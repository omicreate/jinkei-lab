# ソフトテニスIQ｜陣形ラボ

ソフトテニスの陣形をドラッグで自由に試せるコート分析Webアプリです。選手をタップするとセオリー線・返球エリア・デッドゾーンが表示され、相手の守備範囲を「ラケット◯本分」で読めます。競技者・指導者・保護者がスマホ・タブレット・PCのブラウザからそのまま使えます。

## 公開URL

- 使う: https://omicreate.github.io/jinkei-lab/
- リポジトリ: https://github.com/omicreate/jinkei-lab
- 更新記録: [CHANGELOG.md](CHANGELOG.md)

## 主な機能

- 選手をタップでセオリー線・返球エリア・デッドゾーンを表示（最大4人分の同時表示）、ドラッグで自由配置。コート上に「今の穴」（一番遠い担当コース）を表示
- 距離はすべて「ラケット◯本分」換算（1本 = 0.69m）。前衛／後衛で到達目安を分け、ジュニアは歩幅を短く見た閾値に切り替え可能
- 相手選手ごとに担当コース（近い外側とセンター）への距離をコート上とパネルに表示
- 配置プリセット: 正クロス／逆クロス／右ストレート／左ストレート＋チーム別陣形（雁行陣・W後衛・W前衛）
- コートの縦横に実寸ラケットの定規（つかんで平行移動できる物差し）
- ピンチズーム・コートのスライド・90度回転・配置メモリ（端末内3枠）・前提メモ・配置リンク／画像の共有
- オフライン利用に備えたPWA対応（ホーム画面に追加するとアプリのように起動）

## 使い方

1. 公開URLを開きます。
2. 選手をタップしてセオリー線と守備範囲を表示し、ドラッグで配置を動かします。
3. 右端の「設定」から展開・陣形プリセットや利き手・打球面を切り替えます。
4. コート右下のリンクボタンで今の配置URLをコピー、カメラボタンで画像を共有または保存できます。

## データ/プライバシー

端末内の情報と、外へ出す情報は分けています。詳細は [PRIVACY.md](PRIVACY.md) を確認してください。

- アカウント登録はありません。
- 配置メモリ・ヒント表示・ジュニア設定は、利用者のブラウザ内（localStorage）にのみ保存します。開発者や計測先へは送りません。
- 配置リンク（`?layout=`）は、利用者がコピーしたときだけ今の配置をURLに載せます。流入用の `?src=` は共有リンクに含めません。
- 他の面から `?src=` 付きで開いたときだけ、面の識別子とアプリ名を集計用の Google Apps Script へ1回送ります。配置データは含みません。印のないアクセスでは計測しません。
- 前提メモに個人名・学校名などを書いてリンクや画像を共有する場合は、投稿先での見え方に注意してください。

## 技術構成

- 実行方式: Vite + React + TypeScript（ビルド後は静的配信・バックエンドなし）
- PWA: `public/manifest.webmanifest` と `public/sw.js`。Service Worker の事前キャッシュ一覧はビルド時に `scripts/build-sw.mjs` が `dist/sw.js` へ埋め込みます（`npm run build` に含まれます）
- 主なファイル: `src/App.tsx`（画面と状態）、`src/CourtCanvas.tsx`（コート描画と操作）、`src/geometry.ts`（座標・距離計算）、`src/presets.ts`（監修済み基準配置）、`src/layoutShare.ts`（配置リンク）、`src/slots.ts`（端末内メモリ）
- コート寸法は公式規格（23.77m × 10.97m・シングルス幅8.23m）を座標系の基準にしています。
